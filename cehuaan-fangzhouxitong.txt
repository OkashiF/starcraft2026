
# 《星渊黎明》策划案 v2.0 增补  
## 方舟母舰、经营装修与战斗意义系统

## 0. 当前项目判断

现有 README 显示项目已经具备：

- 多战役结构：`campaigns.js`
- 对话脚本：`dialogues.js`
- 科技升级与核心库存：`state.js`
- 单位晋升：`PROMOTION`
- 据点占领：`radar` / `thermal`
- 解锁与进度：`unlock.js`
- 主菜单、HUD、结算弹窗：`ui.js` / `app.js`

因此方舟系统不应另起炉灶，而应作为 **主菜单与战役之间的持久化经营层**：

> 战斗获得核心、老兵、家具、设备、蓝图、遗物  
> → 回到方舟经营、装修、研究、训练  
> → 获得全局加成、战役内支援、空投老兵  
> → 进入下一场更难战役。

---

## 1. 更新后的核心循环

原核心循环：

> 收集资源 → 建设基地与科研 → 组建军队 → 夺取节点 → 推进剧情与解锁科技。

更新为：

> **战役战斗**  
> → 结算：存活老兵、科技核心、战利品、家具/设备图纸、遗物  
> → **方舟经营**：恢复、研究、制造、训练、贸易、医疗  
> → **方舟装修**：布置部门、房间、家具、设备，形成套装与协同  
> → **战前配置**：选择空投老兵、部门支援、全局加成  
> → **下一场战役**  
> → 推进剧情、解锁新部门、新家具、新战役。

战斗不再是“打完就重开”，而是方舟成长的原料来源。

## 2. 方舟母舰总览

### 2.1 定位

方舟是玩家的永久基地，也是主菜单中的核心界面。  
它承担：

- 剧情推进
- 科技核心消费
- 老兵保存与训练
- 家具/设备收藏与装修
- 部门升级
- 战役前配置
- 成就与图鉴展示
- 未来联机/赛季/贸易接口

### 2.2 方舟资源

建议新增方舟专属资源，避免和局内晶矿/瓦斯混淆：

| 资源 | 来源 | 用途 |
|---|---|---|
| 科技核心 | 战役胜利、精英怪、成就 | 部门升级、高级研究、方舟扩建 |
| 合金 | 战斗回收、拆解家具 | 制造设备、维修房间 |
| 数据 | 科研、情报、占领雷达 | 研究、解锁蓝图 |
| 补给 | 战役结算、生态农场 | 空投老兵、治疗、训练 |
| 电力 | 反应堆、电容 | 驱动设备，不足则离线 |
| 算力 | 量子计算机、AI核心 | 科研、情报、自动化 |
| 船员 | 救援任务、生活区、剧情 | 派驻部门，提高效率 |
| 士气 | 生活区、娱乐、胜利 | 影响效率、事件、招募 |
| 声望 | 成就、装修美观、贸易 | 解锁特殊商人、访客、赛季商店 |

### 2.3 方舟等级

方舟等级决定：

- 可开放甲板数
- 房间槽位
- 电力上限
- 部门等级上限
- 可同时派驻船员数
- 可保存装修方案数

示例：

| 方舟等级 | 开放甲板 | 房间上限 | 部门上限 | 说明 |
|---|---|---|---|---|
| 1 | 指挥甲板 | 4 | 2 | 初始 |
| 2 | 工业甲板 | 7 | 4 | 解锁工程 |
| 3 | 科研甲板 | 10 | 6 | 解锁科研 |
| 4 | 军事甲板 | 14 | 8 | 解锁兵营/机库 |
| 5 | 生活甲板 | 18 | 10 | 解锁生活/医疗 |
| 6+ | 遗物甲板 | 22+ | 12+ | 终局 |

## 3. 部门设计

方舟由多个部门组成。每个部门是一个可升级、可装修、可派驻船员的房间群。

| 部门 | 核心功能 | 可放设备/家具示例 | 战斗连接 |
|---|---|---|---|
| 舰桥指挥中心 | 解锁战役、选择空投、指挥官技能槽 | 全息星图桌、战术沙盘、指挥座椅 | 开局资源、技能冷却、波次预览 |
| 动力核心 | 电力上限、应急供电、安全 | 聚变反应堆、备用电池、冷却塔 | 基地建筑血量、断电保护 |
| 科研实验室 | 科技升级、蓝图分析、核心研究 | 量子计算机、样本分析仪、遗物架 | 全局科技、单位升级折扣 |
| 工程制造局 | 制造家具/设备/建筑预制、维修 | 3D打印机、自动维修臂、无人机坞 | 建筑造价、战后修复 |
| 兵营训练舱 | 老兵训练、晋升、技能 | 训练舱、战术模拟器、老兵宿舍 | 初始单位经验、晋升速度 |
| 医疗冻眠舱 | 治疗、复活、保存老兵 | 自动手术台、冻眠舱、纳米修复云 | 老兵提取床位、阵亡回收 |
| 机库军械库 | 空投、装备改装、载具维护 | 空投舱、武器架、护盾发生器 | 空投容量、单位攻击/护甲 |
| 情报通讯 | 地图情报、波次预览、雷达 | 雷达阵列、监听站、密码机 | 显示敌方波次、据点收益 |
| 后勤仓储 | 资源上限、自动采集、贸易 | 仓库、精炼厂、贸易终端 | 初始晶矿/瓦斯、采集效率 |
| 生活娱乐 | 士气、舒适、招募、事件 | 咖啡机、观景窗、酒吧、图书馆 | 船员效率、事件奖励 |
| 生态农场 | 补给、食物、长期维护 | 水培舱、蛋白合成器、生态穹顶 | 战后补给、治疗消耗 |
| 遗物档案馆 | 收藏遗物、全局被动、套装 | 噬星者甲壳、古代AI核心、星门碎片 | 对虫群/护盾/空投特殊加成 |
| 外交/黑市 | 资源兑换、特殊家具、赛季商店 | 贸易桌、加密通讯、黑市终端 | 购买蓝图、稀有设备 |

MVP 优先做：**舰桥、动力、科研、工程、兵营、医疗、机库、情报、生活、仓储**。  
遗物、外交、生态可作为第二阶段。

## 4. 舱室、装修与经营规则

### 4.1 方舟视图

建议采用 **甲板俯视网格 + 房间卡片** 的混合 UI。

- 左侧：甲板/部门列表
- 中间：2D 网格房间视图
- 右侧：家具/设备库存、属性、套装
- 底部：电力、算力、维护、士气、声望

MVP 可先用 DOM + CSS Grid 实现，不急于做 Phaser ArkScene。  
后续再升级为 Phaser 场景，支持拖拽、缩放、动画。

### 4.2 房间规则

每个房间有：

- 类型：指挥、科研、工业、军事、医疗、生活、仓储、遗物
- 等级：1–5
- 尺寸：2×2、3×2、3×3、4×2
- 槽位：可放家具/设备数量
- 门/通道：影响效率与安全
- 电力消耗/产出
- 算力消耗/产出
- 维护消耗
- 舒适/安全/美观

房间可拆除、重建、扩展。拆除返还部分合金，但损失升级材料。

### 4.3 装修加成

家具和设备提供以下属性：

| 属性 | 作用 |
|---|---|
| 功能效率 | 部门生产、研究、训练速度 |
| 电力 | 增加上限或减少消耗 |
| 算力 | 增加科研/情报能力 |
| 维护 | 降低长期消耗 |
| 舒适 | 提高船员效率、士气 |
| 安全 | 降低事故、入侵、火灾 |
| 美观 | 提高声望、访客、成就 |
| 特殊 | 空投容量、老兵床位、初始资源、技能冷却、雷达层数 |

### 4.4 协同规则

让装修不是纯摆放：

- **相邻加成**：医疗舱靠近生活区，恢复效率 +10%
- **套装加成**：同一房间 3 件“科研先驱”套装，研究速度 +15%
- **部门专精**：科研部门只吃科研类设备加成
- **电力平衡**：电力不足时，非核心设备离线
- **安全距离**：反应堆靠近生活区会降低舒适/安全
- **装修方案**：可保存 3 套，如“战斗配置”“科研配置”“生活配置”

## 6. 获取途径

### 6.1 战斗获得

- 战役首通：固定家具/设备/蓝图
- 三星评价：稀有家具
- 精英怪：数据、合金、概率设备
- Boss：史诗/传说遗物
- 据点首次占领：雷达/热能泉专属设备
- 存活老兵：可提取回方舟
- 随机掉落：普通/精良家具

### 6.2 成就获得

- 击杀 1000 敌人：纪念墙
- 无损胜利：指挥座椅
- 占领全部节点：雷达阵列
- 老兵存活 10 场：老兵宿舍
- 装修美观度 100：观景窗
- 不造炮塔获胜：钢铁防线套装

### 6.3 经营获得

- 工程制造局制造
- 科研实验室研究蓝图
- 贸易/黑市兑换
- 随机事件奖励
- 拆解重复家具获得材料

### 6.4 未来玩法接口

- 赛季通行证
- 联机合作战役
- PVP 排名奖励
- 每日/周常任务
- 远征探索

## 7. 让战斗有意义的核心机制

### 7.1 老兵提取与空投

- 战役中单位击杀获得经验，晋升老兵/英雄。
- 战役结束后，存活高星单位可提取。
- 提取占用医疗冻眠舱床位。
- 下一场战役可消耗补给空投。
- 老兵拥有额外血量、射程、技能。
- 阵亡老兵可通过冻眠舱/纳米修复云概率复活。

这会让玩家像爱护 RPG 角色一样爱护高阶兵种。

### 7.2 战利品与永久科技

- 每场战斗掉落科技核心、数据、合金、家具、设备、蓝图。
- 核心用于方舟部门升级。
- 蓝图解锁新设备制造。
- 遗物提供全局被动。
- 重复家具可拆解，形成长期追求。

### 7.3 部门支援

战前可选择 1–3 个部门支援：

- 医疗：开局医疗无人机
- 情报：显示敌方波次
- 工程：开局预制炮塔
- 机库：额外空投老兵
- 动力：基地护盾
- 科研：单位升级折扣

### 7.4 据点战略

据点不仅是局内收益，首次占领还给方舟奖励：

- 雷达站：情报设备、数据
- 热能泉：动力设备、补给
- 轨道炮台：指挥官技能
- 遗物点：遗物档案馆藏品

## 10. MVP 路线图

- 主菜单“方舟”入口

- 部门 1–5 级

- 战斗掉落家具/设备

## 11. 平衡与风险

- 方舟加成不要直接给过强战斗数值，建议以 **5%–15%** 为主。
- 电力/算力限制防止无限堆设备。
- 老兵空投要消耗补给，避免无脑滚雪球。
- 稀有家具以功能+外观为主，避免纯数值碾压。
- 装修方案可保存，降低反复调整成本。
- 存档要版本迁移，避免旧档损坏。

## 12. 一句话总结

**方舟系统把“打赢一场”变成“经营一艘船、装修一个家、培养一支老兵、解锁一条科技线、反哺下一场战斗”。**  
这样战斗才有意义：每一次胜利都会回到方舟，变成可见、可摸、可装修、可成长的东西。
